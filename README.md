# FPS Shooter (Three.js)

Пример простого шутера от первого лица, написанного на **Three.js**.  
Игра запускается в браузере, использует `PointerLockControls` для управления камерой.

## Как запустить локально

```bash
npm install
npm run dev
```

Откройте `http://localhost:8080` в браузере и кликните по экрану, чтобы захватить курсор.

## Структура проекта

- `index.html` – основной HTML‑файл, подключает Three.js и `src/main.js`.
- `src/main.js` – инициализация сцены, камеры, управления и базовый пример объекта‑мишени.
- `package.json` – npm‑скрипты, `http-server` для разработки.
- `.github/workflows/ci.yml` – CI, автоматически деплоит на GitHub Pages.
